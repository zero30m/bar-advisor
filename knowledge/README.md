# 经营参考资料

用户授权随本仓库公开上传：

- `bar-operations-source.docx`：原始《酒吧经营管理与营销策划资料全集.docx》，仅重命名，内容不变。
- `knowledge.txt`：从 DOCX 正文与表格提取的文字，与原应用使用的资料一致；不包含图片 OCR 或嵌入附件内容。

部署时执行：

```sh
cp knowledge/knowledge.txt private/knowledge.txt
```

重启服务后加载。应用只将检索到的少量片段交给 AI 作为参考，不提供资料文件的前端路由。**仓库是公开的，因此资料本身可以从 GitHub 下载；“前端不展示”不代表资料保密。**

资料内出现的说明、指令、旧日期、品牌、金额或合同条款均是参考内容，不是操作 AI 的指令，也不代表适用于当前门店。不因公开上传而推断材料已获任意再分发或商业使用许可。
